# Banco de Dados 2026.2

Repositório com todo o conteúdo produzido na disciplina de **Banco de Dados** do curso de Análise e Desenvolvimento de Sistemas (ADS) — SPTech, semestre 2026.2.

Aqui estão reunidos exercícios de sala, atividades avaliativas e o projeto integrador (PI) desenvolvidos ao longo do semestre, com scripts SQL cobrindo desde a criação de tabelas até comandos de manipulação e alteração de dados.

## Estrutura do repositório

```
├── Exercícios Pré-Sprint/
│   └── pre-sprint.sql
├── Introdução - Banco de Dados/
│   ├── ex1.sql
│   ├── ex2.sql
│   ├── ex3.sql
│   ├── ex4.sql
│   └── ex5.sql
├── Update, Delete, Alter Table e Truncate - Banco de Dados/
│   ├── Atividade2-ex1.sql ... Atividade2-ex7.sql
│   ├── Controle-de-Corridas.html
│   └── Modelo - Linha da Vida SPTECH.pdf
└── PI - Banco de Dados/
    └── pi-banco-de-dados.sql
```

### Descrição das pastas

- **Exercícios Pré-Sprint** — exercícios introdutórios de modelagem e criação de tabelas em SQL.
- **Introdução - Banco de Dados** — primeiros comandos DDL/DML: `CREATE TABLE`, `ALTER TABLE`, `INSERT`, `SELECT` e `UPDATE`.
- **Update, Delete, Alter Table e Truncate - Banco de Dados** — atividade avaliativa com foco em comandos de manipulação e alteração de estrutura (`UPDATE`, `DELETE`, `ALTER TABLE`, `TRUNCATE`), incluindo material de apoio (HTML e PDF).
- **PI - Banco de Dados** — script SQL do Projeto Integrador, com modelagem de banco de dados aplicada ao projeto **SiloTech** (monitoramento de silos via sensores).
